# ТЗ: редизайн Weekly Collector

## Цель

Сделать collector рабочим инструментом для быстрого еженедельного интервью по темам из вкладки `Активные`. Это не landing page и не аналитический dashboard. Главная задача интерфейса: без шума пройти темы по порядку, записать факт недели, итог, следующую веху, мяч и вопрос к Евгению, затем безопасно записать результат в Google Sheet.

## Контекст реализации

- Текущий UI зашит в `src/weekly_assistant/collector_server.py` как plain HTML/CSS/JS: `INDEX_HTML`, `APP_CSS`, `APP_JS`.
- Без React/Vite/сборки. Нужен дизайн, который можно перенести в текущий vanilla frontend.
- Backend API уже есть: `/api/session`, `/api/row`, `/api/status`, `/api/draft`, `/api/chatgpt-context`, `/api/chatgpt-import`, `/api/export`, `/api/write-back`, `/api/start-next-week`.
- `movement_type`, `needs_sync`, `sync_reason` остаются в данных и JSON, а в Google Sheet пишутся в скрытые служебные колонки.

## Основной пользовательский сценарий

1. Пользователь открывает collector.
2. Видит период недели, источник `Активные`, прогресс по темам и очередь тем.
3. Нажимает `Copy ChatGPT context`, проходит интервью в ChatGPT с `T-001`, получает JSON.
4. Импортирует JSON обратно.
5. Проверяет каждую тему: факт, итог, вехи, мяч, вопрос.
6. При необходимости правит руками.
7. Нажимает `Export` для локальной проверки.
8. Нажимает `Write Active` для записи в Google Sheet.

## Информационная архитектура

Экран должен быть трехзонным:

1. Левая колонка: управление сессией и очередь тем.
2. Центральная зона: редактор текущей темы.
3. Правая зона: контекст и проверка.

Левая колонка:

- период недели;
- крупные действия: `Copy ChatGPT context`, `Import JSON`, `Export`, `Write Active`;
- компактный прогресс: всего active, заполнено, изменено, есть вопросы;
- список тем с `T-001`, названием, статусом заполнения и маленьким индикатором изменения;
- добавление новой строки должно быть вторичным, не первым экраном.

Центральная зона:

- заголовок текущей темы: `T-001`, название, row number, секция;
- быстрые статусы: `Результат`, `Процесс`, `Вопрос`, `Не трогал`;
- поля в таком порядке:
  - `Сырой ввод`;
  - `Итоговая формулировка`;
  - `Все вехи`;
  - `Мяч`;
  - `Вопрос к Евгению`;
  - `Факты этой недели` как свернутое/вторичное поле, если оно нужно для проверки;
- действия рядом с формой: `Save`, `AI draft`, `Next empty`.

Правая зона:

- `Прошлая неделя` как read-only контекст;
- текущие/старые вехи как read-only контекст, чтобы не потерять срок;
- `AI draft`;
- `Singularity`;
- блок редактирования строки (`Название`, `Тип`, `Focus`, `Дата постановки`) должен быть свернутым разделом `Настройки строки`.

## Служебные поля Google Sheet

Эти поля не являются основными weekly-колонками и должны храниться в Google Sheet как hidden columns:

- `movement_type`;
- `needs_sync`;
- `sync_reason`.

Они должны продолжать:

- попадать в JSON import/export;
- сохраняться в session;
- обновляться через ChatGPT import, AI draft и быстрые статусы;
- использоваться backend-логикой для summary/export;
- создаваться в конце вкладки `Активные` и сразу скрываться через `hiddenByUser`.

## UX-требования

- Первый экран должен сразу показывать очередь тем и редактор текущей темы, без маркетинговых блоков.
- Интерфейс должен быть плотным, рабочим, спокойным: меньше декоративных карточек, больше читаемых областей.
- Главные действия должны быть визуально разделены:
  - безопасные: `Save`, `Copy ChatGPT context`, `Export`;
  - рискованные/финальные: `Write Active`, `Start next week`, `Archive`.
- `Write Active` и `Start next week` должны выглядеть как действия, требующие проверки.
- В списке тем должно быть понятно, какие темы уже импортированы из ChatGPT, какие изменены вручную, какие пустые.
- Вехи должны быть полноценным полем, не спрятанным после даты. Основной пользовательский вопрос: "когда докатимся и куда".
- Текст в кнопках и полях не должен обрезаться на мобильной ширине.
- На ширине до 980px колонки должны складываться: очередь, редактор, контекст.

## Визуальное направление

- Стиль: рабочий internal tool, не SaaS landing.
- Радиусы до 8px.
- Без декоративных градиентов, орбов, иллюстраций и hero-блоков.
- Цвета: нейтральная светлая база, один акцент для primary action, отдельный спокойный warning для финальных действий.
- Шрифты: системные, без viewport-based font scaling.
- Карточки использовать только для повторяющихся тем в очереди и ограниченных блоков контекста, не вкладывать карточки в карточки.

## Acceptance criteria

- Пользователь может пройти `T-001 -> T-002 -> ...` без необходимости думать о служебных полях.
- `movement_type`, `needs_sync`, `sync_reason` пишутся в скрытые колонки Google Sheet и сохраняются в session/import.
- ChatGPT import делает текущей первую импортированную тему и визуально показывает, что строки обновлены.
- Перед `Write Active` пользователь видит все поля, которые реально пойдут в `Активные`: итог, вехи, мяч, вопрос.
- На desktop 1440px видны очередь, редактор и контекст одновременно.
- На mobile/tablet нет наложения текста, переполнения кнопок и горизонтального скролла.
