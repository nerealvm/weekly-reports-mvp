# Movement Rules

Реальное движение считается только по предъявляемому результату:

- создан или отправлен документ;
- принято решение;
- согласован следующий шаг;
- получен артефакт;
- мяч передан следующей стороне.

Не считается движением:

- просто созвон;
- обсуждение без outcome;
- размышления;
- `в процессе` без результата;
- `не двигал`.

Если фактуры мало, строка получает `unclear`, а не выдуманный прогресс.
