# Prompt Rules

AI drafting layer должен предлагать строку целиком.

Правила:

- писать через результат, а не процесс;
- не выдумывать даты, артефакты и решения;
- не использовать прошлую неделю как факт нового weekly;
- не использовать перенесенные поля как новую фактуру без ручного изменения в текущей session;
- если движения нет, честно писать `не двигал` / `без движения`;
- открытый вопрос должен быть явно заданным вопросом к Евгению, а не внутренним todo или выводом из старого контекста;
- `На чьей стороне мяч` должен быть однозначен;
- при неясной вехе сначала переносить прошлую, потом просить уточнение.
