# Weekly Viewer

Read-only веб-интерфейс для просмотра weekly-отчета Евгением.

## Запуск

```bash
make viewer
```

Открой:

```text
http://127.0.0.1:8770
```

## GitHub Pages

Для публикации snapshot-интерфейса Евгения:

```bash
make pages-export
```

Команда обновляет fallback snapshot:

```text
docs/report.json
```

Pages-интерфейс живет в `docs/index.html` и `docs/src/`. Основной режим без API key — публичный CSV Google Sheets через `gviz/tq`, если таблица доступна всем по ссылке. `report.json` остается fallback на случай, если публичный CSV недоступен.

Запись комментариев в Google Sheets доступна только в локальном `make viewer`, потому что GitHub Pages не выполняет Python backend.

## Что показывает

- активные темы из `Weekly MVP 2026-05-08`;
- итоговую формулировку недели;
- вехи;
- на чьей стороне мяч;
- вопросы к Евгению;
- темы, где нужен sync.

## Комментарии Евгения

В любом поле карточки можно нажать на область поля или иконку комментария и оставить вопрос/комментарий.

Открытые комментарии показываются прямо под соответствующим полем.

Комментарий можно набрать текстом или надиктовать кнопкой `Голосом`, если браузер поддерживает Web Speech API.

После сохранения тема убирается из левой панели внимания: это означает, что по ней уже есть реакция Евгения.

Комментарии сохраняются локально и сразу пишутся в отдельную вкладку той же Google Sheets таблицы:

```text
exports/viewer_feedback/
Weekly Feedback
```

Кнопка `Комментарии` в верхней панели копирует все открытые комментарии одним текстом.

Если запись в Google Sheets не удалась, интерфейс показывает уведомление. Локальная копия при этом сохраняется.

Сохранение работает асинхронно: окно комментария закрывается после локального сохранения, а статус записи в Google Sheets показывается отдельным уведомлением.

## Фильтры

- `Все`;
- `Нужен sync`;
- `Вопросы`;
- `Есть движение`;
- `Без движения`;
- поиск по теме, результату, вехе и мячу.

## Сортировка

По умолчанию:

1. темы, где нужен sync;
2. темы с вопросами к Евгению;
3. focus-темы;
4. темы с реальным движением;
5. unclear;
6. темы без движения.

## Ограничения

- Интерфейс читает weekly-данные из Google Sheet.
- Комментарии пишет в отдельную вкладку `Weekly Feedback`, а не в native cell comments Google Sheets.
- Источник данных — текущая нормализованная weekly-вкладка.
- Для внешнего доступа Евгению потребуется отдельный деплой или туннель; локальный `127.0.0.1` доступен только на этой машине.
