# Weekly Collector

Локальный browser-инструмент для еженедельного сбора фактуры без работы в VS Code.

## Запуск

```bash
make collector WEEK_START=2026-05-01 WEEK_END=2026-05-08
```

По умолчанию запуск продолжает существующую session. Если нужно полностью перечитать Google Sheet и начать заново:

```bash
make collector WEEK_START=2026-05-01 WEEK_END=2026-05-08 COLLECTOR_REFRESH=--refresh
```

Открой:

```text
http://127.0.0.1:8765
```

`WEEK_END` — правая граница периода, то есть следующая пятница. Для периода пятница-пятница `2026-05-01 - 2026-05-08` факты собираются за неделю, начинающуюся 1 мая и заканчивающуюся перед 8 мая.

## Что делает

- скачивает вкладку `Активные` из Google Sheet;
- присваивает строкам сквозные `T-001`, `T-002`, ... на время сессии;
- показывает active-темы;
- подтягивает подсказки из Singularity по `config/singularity_projects.csv`;
- дает быстрые статусы: результат, процесс, вопрос, не трогал;
- принимает сырой текст по теме;
- умеет разложить bulk dump по темам через OpenAI;
- копирует контекст для ChatGPT Project;
- импортирует финальный JSON из ChatGPT Project;
- генерирует AI draft для строки;
- добавляет новые строки в `Активные`;
- редактирует название, тип и focus строки;
- позволяет локально менять тип строки для сессии;
- может скрыть строку в текущей локальной сессии через `Archive`; перенос между вкладками `Активные` / `Архив` остается ручным действием в Google Sheet;
- начинает следующую неделю без перезапуска: автоматически рассчитывает период пятница-пятница, переносит итог активных строк в `Результат прошлой недели` и очищает weekly-поля;
- сохраняет session локально;
- экспортирует candidate CSV, questions, sync и summary;
- может записать результат обратно в недельные колонки `Активные`.

## Где лежит session

```text
exports/collector_sessions/<week-start>_<week-end>/
```

Основные файлы:

```text
session.json
source.csv
candidate.csv
questions.txt
sync.txt
summary.txt
milestones.txt
chatgpt_context.json
```

## Рабочий сценарий

1. Запусти `make collector`.
2. Если работаешь через ChatGPT UI: нажми `Copy ChatGPT context`.
3. Вставь контекст в ChatGPT Project с prompt из `docs/chatgpt_weekly_project_prompt.md`.
4. Пройди интервью в ChatGPT и скопируй итоговый JSON.
5. Вставь JSON в поле `ChatGPT JSON` и нажми `Import ChatGPT JSON`.
6. Проверь строки в collector.
7. Если нужно, добавь новые строки в блоке `Новая строка`, либо отредактируй выбранную строку в правом блоке `Строка`.
8. Нажми `Export`.
9. Если результат нормальный, нажми `Write Active`.

Альтернативно можно работать внутри collector: вставить общий сырой weekly dump в `Сырой dump`, нажать `Разложить по темам`, пройти темы и нажимать `AI draft`.

## Управление строками

- `Новая строка` создает локальную строку с новым `Topic ID` вида `T-###`; в Google Sheet она попадет после `Write Active`.
- `Write Active` добавляет новые строки в `Активные`.
- Тип `Проект` / `Задача` / `На холде` меняет локальную классификацию строки в session.
- `Archive` скрывает строку из текущего локального списка. Если нужно перенести ее из `Активные` в `Архив`, это делается вручную в Google Sheet.
- Weekly-правки пишутся в найденные по заголовкам колонки `Статус предыдущей недели`, `Куда мы докатились на этой`, `Когда докатимся и куда`, `На чьей стороне мяч`, `Открытые вопросы`.

## Новая неделя без перезапуска

Кнопка `Start next week` автоматически рассчитывает следующий отчетный период пятница-пятница. Для текущих старых session с концом недели в четверг, например `2026-05-08 - 2026-05-14`, следующий период будет `2026-05-15 - 2026-05-22`. Затем для active-строк:

- переносит `Итоговая формулировка` / `AI draft result` / `Факты этой недели` в `Результат прошлой недели`;
- очищает `Факты этой недели`, `AI draft result`, `Итоговая формулировка`;
- сбрасывает `Movement type` в `unclear`, `Review status` в `draft`;
- пересчитывает `Нужен sync` по открытому вопросу, мячу у Евгения и focus-правилам.

После этого нажми `Write Active`, чтобы зафиксировать новую неделю в Google Sheet.

## Запись в `Активные`

- `Write Active` создает недостающую дату недели сразу в трех группах: `Статус предыдущей недели`, `Куда мы докатились на этой`, `Когда докатимся и куда`.
- `Статус предыдущей недели` заполняется копией предыдущего результата по теме.
- `Куда мы докатились на этой` получает `Итоговую формулировку`.
- `Когда докатимся и куда` получает вехи.
- `На чьей стороне мяч` и `Открытые вопросы` пишутся в их существующие колонки.
- `Movement type`, `Нужен sync` и `Причина sync` пишутся в скрытые служебные колонки в конце вкладки `Активные`.
- Основной сценарий не создает `Weekly MVP`, `Weekly Questions` и `Weekly Sync` вкладки.
- Обычный `Export` остается локальным и не меняет Google Sheet.

## Правила AI draft

- `Прошлая неделя` в правой панели — только справка для человека.
- AI draft не использует прошлую неделю как факт нового отчета.
- AI draft не использует импортированные из таблицы `Факты этой недели`, пока ты не изменил их в текущей session.
- `Вопрос к Евгению` появляется только если ты явно написал его в сыром вводе или руками заполнил поле вопроса.
- Если новой фактуры нет, строка должна честно уйти в `no_movement`.

## Вехи

- Внутри session поддерживается несколько вех через `milestones[]`.
- В UI поле `Все вехи` хранит одну веху на строку.
- При записи в Google Sheet все вехи собираются в одну строку через `;` в поле `Ближайшая веха`.
- `Дата вехи` получает дату первой вехи, то есть ближайшей.

## Правила безопасности

- `Write Active` пишет измененные строки и колонку `Статус предыдущей недели` для строк текущей сессии.
- Обычный запуск не перезатирает локальную session.
- `COLLECTOR_REFRESH=--refresh` перезагружает session из Google Sheet и может стереть локальные черновики, если они не записаны в Sheet.
- Weekly-правки пишутся по найденным заголовкам, а не по жестко заданным буквам колонок.
- Если формулировка сомнительная, сначала `Export`, потом ручной просмотр.
