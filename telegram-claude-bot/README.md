# telegram-claude-bot

Личный Telegram-бот: пересылаешь ему любое сообщение — текст, голосовое,
картинку, документ — и он мгновенно запускает **новый чат с Claude-агентом**,
который разбирает сообщение (что это, суть, следующие шаги) или выполняет
поручение, если оно написано рядом.

Как это работает:

- Каждое новое сообщение боту = новая агент-сессия (Claude Agent SDK,
  полноценный агент с файлами, bash и веб-поиском в контейнере).
- Ответ (reply) на любое сообщение бота **продолжает ту же сессию** — контекст
  сохраняется, можно уточнять и давать следующие задания.
- Голосовые и аудио расшифровываются локально (faster-whisper), в облако аудио
  не уходит.
- Картинки и документы сохраняются в рабочую папку агента, он их читает сам.
- Доступ только у пользователей из `ALLOWED_USER_IDS`, остальных бот игнорирует.

## Установка

Нужен любой сервер/VPS (или домашняя машина) с Docker.

1. **Создай бота**: напиши @BotFather → `/newbot` → получи токен.
2. **Узнай свой Telegram id**: напиши @userinfobot.
3. **Получи токен Claude** (один из вариантов):
   - подписка Pro/Max: на любой машине с установленным Claude Code выполни
     `claude setup-token` и скопируй OAuth-токен;
   - или создай API-ключ на platform.claude.com (оплата за токены).
4. **Разверни**:

```bash
git clone https://github.com/nerealvm/telegram-claude-bot.git
cd telegram-claude-bot
cp .env.example .env
nano .env          # вставь токены и свой id
docker compose up -d --build
```

Проверка: напиши боту `/start`, затем перешли ему любое сообщение.

Логи: `docker compose logs -f`. Обновление: `git pull && docker compose up -d --build`.

## Замечания

- Первая расшифровка голосового скачивает модель whisper (~500 МБ для `small`)
  — это одноразово, модель кэшируется в контейнере (пересборка сбрасывает кэш).
- Агент запускается с `bypassPermissions` **внутри контейнера** — он может
  выполнять команды и ходить в интернет, но только в изоляции Docker. Не
  запускай бота без контейнера на машине с чувствительными данными.
- Альбом из нескольких фото приходит отдельными сообщениями — каждое откроет
  свою сессию. Если нужно разобрать вместе, пришли фото по одному реплаем в
  одну ветку.
- Память между сессиями: рабочая папка `/data/workspace` общая для всех сессий,
  агент может сохранять туда заметки и результаты.

## Структура

```
bot/
  main.py           # aiogram-хендлеры, сборка промпта из сообщения
  claude_runner.py  # запуск сессий через claude-agent-sdk
  sessions.py       # sqlite: ветка переписки -> session_id
  transcribe.py     # faster-whisper для голосовых
  config.py         # конфигурация из .env
```
